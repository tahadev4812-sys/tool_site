Image Resizer

Resize one picture or a whole batch to the exact size you need. Pick a percentage, width or height — the aspect ratio is kept automatically.

How to use this tool

  1. Add your images to the box.
  2. Choose how to resize: by percentage, width or height, and enter the value.
  3. Keep original format, or pick PNG, JPG or WebP for the output.
  4. Check the new dimensions in the list and download your resized pictures.

How resizing keeps the proportions

by width: new height = old height × (new width ÷ old width) by height: new width = old width × (new height ÷ old height) by percent: both sides × (percent ÷ 100)
ExampleA 4000 × 3000 px photo set to 1200 px wide becomes 1200 × 900 px (3000 × 1200 ÷ 4000 = 900). Setting it to 50% gives 2000 × 1500 px.

Percentage, width or height?

Use percentage to shrink everything by the same amount, for example 50% for half-size pictures. Use width when a website or template specifies a width, such as 1200 px, and let the height follow. Use height for banners and icons where the height is the fixed measurement.

Enlarging has limits

Making an image smaller is safe. Making it larger cannot add detail that was never there, so enlarged pictures look soft or pixelated. If you need a bigger version, start with the highest-resolution original you have.

Resizing vs cropping

Resizing changes the overall dimensions while keeping the whole picture. If you need a specific shape, like a square avatar from a wide photo, you will also need to crop it in an editor.

Frequently asked questions

How do I resize an image without losing quality?

Shrinking an image loses very little visible quality. Use the original file, keep the format lossless (PNG) or high quality (90%+), and avoid enlarging.

Does the aspect ratio stay the same?

Yes. You set one value (percentage, width or height) and the other side is calculated automatically.

Can I resize many images at once?

Yes. Every file is resized with the same setting and you can download all of them together.

What size should I use for a website?

For full-width images, 1600–1920 px is plenty. For blog photos, 1200 px usually works well.

Does resizing change the file size?

Usually yes. Fewer pixels means a smaller file. Use the compressor for extra savings.

Are my images uploaded?

No. All resizing happens in your browser.

Can I make an image bigger?

You can, but the image will look softer because no new detail is created.
